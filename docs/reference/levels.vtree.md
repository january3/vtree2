# Get the levels of a vtree object

Get the levels of a vtree object

Returns a list of character vectors, one for each variable split in the
tree, with each ordered vector containing the levels of that variable.

## Usage

``` r
# S3 method for class 'vtree'
levels(x)

# S3 method for class 'vtree'
levels(x)
```

## Arguments

- x:

  A vtree object.

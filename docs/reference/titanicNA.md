# titanicNA dataset

Based on the Titanic dataset, some observations have been randomly
replaced with NAs to simulate missing data.

## Usage

``` r
titanicNA
```

## Format

A data frame with 2201 rows and 4 variables:

- Class:

  Passenger class (1st, 2nd, 3rd, Crew)

- Sex:

  Passenger sex (Male, Female)

- Age:

  Passenger age group (Child, Adult)

- Survived:

  Survival status (Yes, No)

## Source

Simulated data
